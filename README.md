# Data Science Projekt: Kreditausfallprognose

## Projektbeschreibung
Ziel dieses Projekts ist die Entwicklung eines datengetriebenen Modells zur Vorhersage von Kreditausfällen. Auf Basis historischer Kreditdaten untersuchen wir relevante Einflussfaktoren und trainieren Machine-Learning-Modelle, um einzuschätzen, ob ein Kredit voraussichtlich zurückgezahlt wird oder ausfällt.

## Projektziele
- Daten verstehen und explorativ analysieren (EDA)
- Daten bereinigen und geeignete Features entwickeln
- Verschiedene Machine-Learning-Modelle trainieren und vergleichen
- Die Vorhersagequalität anhand geeigneter Metriken bewerten
- Die Ergebnisse interpretieren und nachvollziehbar dokumentieren

## Technologien
- Python
- Pandas und NumPy
- Matplotlib und Seaborn
- Scikit-learn
- Jupyter Notebook / Google Colab
- Git und GitHub

## Projektstruktur (Kann bei Bedarf geändert werden)
- `data/` – Datensätze und aufbereitete Daten
- `notebooks/` – Datenanalyse und Modellversuche
- `models/` – Trainierte Modelle
- `README.md` – Projektdokumentation

## Teamarbeit
Wir entwickeln das Projekt gemeinsam mit Git und GitHub. Analysen, Code und Modellierung werden versioniert, dokumentiert und schrittweise zusammengeführt.

## Ergebnis
Ein nachvollziehbares und leistungsfähiges Prognosemodell, das das Risiko eines Kreditausfalls einschätzt und die wichtigsten Einflussfaktoren transparent macht.
